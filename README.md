# Chinese Poetry Knowledge Base

本项目基于 [Werneror/Poetry](https://github.com/Werneror/Poetry)，旨在构建一个便于与数据库同步的知识库。喜欢本项目的请先去原项目点个赞，谢谢。

特殊说明：
* 原项目有个大家比较关心的问题，就是朝代更迭的作者、作品是怎么划分的，我会尽量按照下面的逻辑进行调整：
    - 无论作品创作于什么时候，一律归属到作者所在的朝代；
    - 作者所属的朝代，以作者的“灵魂”归属为主要参考，这个描述比较模糊，也会很主观，举两个例子：
        + 曹操的时代完全处在东汉，但建安文学是所谓魏晋风骨的重要组成，曹操也是曹魏的实际开创者，因此划分到魏晋时代；
        + 与曹操同时代的孔融，是完全意义上的汉臣，虽然是建安七子之一，也是建安文学的重要代表，却会被划分到汉代。
* 诗与词以是否有 rhythmic 字段区分，只有词会有这个字段，即词牌名。

每次有更新时，根据 git commits 记录找到有变更的诗词，然后根据 id 字段更新到数据库。

### V1.0.1

对部分数据进行重排&去重：

汉.json：
* 《何秀才》一共六首，其中五首应该是司马光所作的《何秀才郊园五首》，还有一个汇总版，汇总版已删除。其余五首按汇总版顺序重命名为《何秀才郊园五首·其X》。作者和朝代暂不修改。

魏晋.json：
* 魏晋.json 的古诗五首，并不是组诗，应当是汉代作品，暂时保留在魏晋目录中；
* 魏晋.json 的古诗十九首，也应当是汉代作品，暂时保留在魏晋目录中；
* 魏晋.json 的《古诗三首》，删除了汇总版，但似乎佚失了其二；
* 魏晋.json 的《赠刘琨诗》存在问题，有两个其二，暂未处理，被删除的汇总版与分节的《其一》至《其十九》总和一致，《赠刘琨诗二十首·其二》也应该排进去；
* 《李陵录别诗二十一首·其十五》和《李陵录别诗二十一首·其十六》有两句重复。
* 《百一诗里面》，有一个《其十九》包含了另一版本的《其十九》至《其二十二》。有两个《其十》且不一样（《其九》包含了一个《其十》），最终的汇总版包含了两个《其十》，但不包含《其十九》。
* 《子夜歌四十二首》的分节版与被删掉的汇总版都缺《其四十一》。
* 《懊侬歌十四首》的分节版与被删掉的汇总版都《缺其八》。
* 《子夜四时歌·冬歌十七首》的分节版与被删掉的汇总版都缺《其十六》。
* 《团扇郎六首》的分节版与被删掉的汇总版都缺《其二》。
* 《晋江左宗庙歌十一首》被删除的汇总版只包含了分节版的《其一》至《其十》。
* 《估客乐》有两个《其一》、两个《其二》，与两个汇总版，根据网络资料重整为《其一》至《其四》。
* 《登临海峤初发彊中作与从弟惠连可见羊何共和之诗》部分分节作“疆中”，似乎应该是“彊中”。
* 《李陵录别诗二十一首·其十六》应该是错误的。
* 《桃叶歌三首·其二》有两个版本，一个记为王献之所作，第二句为“桃叶连桃根”，另一个记为无名氏所作，第二句为“桃树连桃根”。根据识典古籍，取后者，并把作者改为王献之。
* 《桃叶歌三首·其三》有两个版本，一个记为王献之所作，第四句为“我自迎接汝”，另一个记为无名氏所作，第二句为“我自来迎接”。根据识典古籍，取后者，并把作者改为王献之。
* 另有一首单篇《桃叶歌》，作者无名氏。根据识典古籍，这也是王献之所作，应该是“其四”，但这样就不是《桃叶歌三首》了，只把作者改为王献之，没改标题。
* 《晋四厢乐歌三首》很乱，作者无名氏，从宋书来看，是不同作者所作的组诗，以及对应的汇总版，目前按作者进行了重新分组，并删除汇总版，句子太散，可参照识典合并成一句。
* 《采桑度》仅一三六。

南北朝
* 《梁三朝雅乐歌十九首》共38首，原版全部标记为沈约所作，但根据《乐府诗集》（https://www.shidianguji.com/zh/book/SBCK309/chapter/SBCK309_154）有一半是萧子云所作。并且十九首分属于俊雅、寅雅、介雅、需雅，现在的分节标题可能不够明确，但暂不做修改。已修改作者并删除对应的汇总版。
* 吴均的《行路难五首·其四》和费昶的《行路难二首·其一》九句完全一样。不知道谁抄谁，都保留了。
* 沈约的《咏竹诗》和刘孝先的《咏竹诗》都有“无人赏高节，徒自抱贞心”。且沈约版只此一句，疑似应该是刘孝先作，暂时都保留。
* 张正见的《陇头水二首·其二》和徐陵的《陇头水》第四联相同，前三联仅个别字有差，暂时都保留。
* 萧纲的《诗》只有一句“绮花非一种，风丝乱百条”。这句是《三月三日率尔成诗》中的一句。已删除。
* 萧纪的《晓思诗》和萧纲的《晓思诗》只有个别字不同，根据《汉魏六朝百三家集》，应该是萧纪作，但因为有些字不同，都保留。
