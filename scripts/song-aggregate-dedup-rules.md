# 诗词分节版与汇总版去重规则

本文档用于指导 `duplicate.md`、`duplicate_song.md` 中诗词重复记录的自动清理与人工复核。

## 一、候选关系识别

仅比较同一 JSON 文件、同一作者的记录。

汇总版标题需满足至少一种关系：

- 与某个分节标题完全相同；
- 等于某个分节标题去掉 `·其X` 后的结果。

例如：

- 《郑闳中挽辞二首·其二》与同名分节；
- 《南郊大礼庆成诗五首·朝享景灵宫》对应《南郊大礼庆成诗五首·其一·朝享景灵宫》。

当前规则不能自动识别与分节标题完全没有上述结构关系的误题汇总版，此类记录需要人工复核。

## 二、内容条件

汇总版必须能够无损拆分为至少两个现有分节：

- 每一块必须与某条分节记录的完整 `verses` 完全一致；
- 不能只匹配分节中的部分句子；
- 汇总版不能含有分节版之外的独有内容；
- 汇总版内部的分节顺序不受限制；
- 汇总版可以只包含完整分节中的一部分，不必覆盖全部分节。

因此：

- `其二＋其一` 形式的倒序汇总版可以删除；
- 缺少某个分节的残缺汇总版也可以删除，只要汇总版现有的全部内容均可由完整分节还原。

## 三、分节完整性与顺序

对应的分节系列必须满足：

- 现存分节在文件中的排列位置按题号递增；
- 允许从其二或其他题号开始，也允许中间缺号；
- 题名中声明的篇数不要求全部存在；
- 分节不要求在文件中紧密相邻，但现存分节的前后顺序必须正确。

例如：

- 汇总版只使用其一、其三，即使其二缺失，只要其一、其三在文件中按序排列，也可以删除；
- 汇总版使用到其十七，不要求其一至其十六全部存在，只要求现存分节按题号递增；
- 题名为“十首”，即使只存在其一、其二，也不因其三至其十缺失而阻止删除汇总版。

## 四、保留条件

出现以下任一情况，不删除汇总版：

- 汇总版存在分节版没有的独有内容；
- 汇总版只能匹配分节中的部分句子；
- 分节在文件中的位置没有按题号递增；
- 内容需要借用不同作者或不同文件的记录才能拼成；
- 无法确认各内容块属于同一标题系列。

## 五、删除后的同步处理

每删除一条汇总版：

1. 仅从对应 JSON 删除汇总记录，保留所有分节；
2. 从 `duplicate_song.md` 删除所有由该汇总记录产生的重复关系，包括：
   - 与组成分节的完整重复；
   - 与其他记录因公共句产生的附带重复；
3. 向 `removed.txt` 追加一行：

```text
〔宋·作者〕汇总版标题
```

## 六、已确认示例

### 可以删除

- 韩维《郑闳中挽辞二首·其二》：汇总内容为其二加其一，分节其一、其二完整有序。
- 张九成《论语绝句》：分节其一至其一○○完整；汇总版只收其中九十九首并遗漏其二十二，但没有独有内容。

### 缺号但仍可删除

- 杨亿《建溪十咏·武夷山》：即使分节缺少其三，只要汇总版不含现存分节之外的独有内容，仍可删除。
- 杨无咎《柳梢青·其五》：即使分节缺少其二、其三、其四、其十等题号，只要现存分节有序且汇总版可由其完整还原，仍可删除。
